# IEEE CS KIIT SBC Landing Page

The official web platform for the IEEE Computer Society Student Branch Chapter at KIIT University. This project showcases the chapter's mission, objectives, and community impact through a premium, high-performance digital experience.

## ✨ Features
- **Modern UI/UX**: Premium dark theme with glassmorphism effects.
- **High Performance**: Built on Vite for lightning-fast load times.
- **Fluid Animations**: Integrated GSAP for scroll-triggered interactions and smooth transitions.
- **Responsive Design**: Fully optimized for all device sizes (Mobile, Tablet, Desktop).
- **Interactive Elements**: Custom canvas explosions and dynamic navbar.

## 🛠️ Tech Stack
- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Animations**: [GSAP](https://greensock.com/gsap/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Styling**: Vanilla CSS (Custom tokens and glassmorphism)

## 🚀 Getting Started

### Prerequisites
- Node.js (Latest LTS recommended)
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/kpramod0/IEEE.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
